
# 🌞 Solar AI Assistant - Groq API Powered Chatbot

🚀 **Solar AI Assistant** is an AI-powered chatbot that provides expert insights on **solar energy**, including installation tips, cost savings, and the latest advancements in solar technology.  

✅ **Powered by Groq API** (No Hugging Face, No Torch)  
✅ **FastAPI Backend + Streamlit Frontend**  
✅ **Deployed on Render**  

---

## **📌 Features**
✔ **Solar Energy Expert:** Get answers to questions about solar panels, efficiency, and installation.  
✔ **Lightweight & Fast:** Uses Groq API instead of Hugging Face, making it efficient.  
✔ **Web-Based Interface:** Built with **FastAPI & Streamlit** for seamless interaction.  
✔ **Deployed on Render:** No local setup required—just use the live app!  

---

## **📌 Tech Stack**
| **Technology** | **Usage** |
|--------------|---------|
| **FastAPI** | Backend API for handling user queries |
| **Groq API** | Provides AI-generated responses |
| **Streamlit** | Frontend UI for user interaction |
| **Render** | Cloud deployment platform |
| **Python** | Main programming language |
